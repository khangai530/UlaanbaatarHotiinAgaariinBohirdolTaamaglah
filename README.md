# Улаанбаатар хотын PM2.5 агаарын бохирдлын таамаглал

Цаг агаарын өгөгдлөөр PM2.5-ийг таамаглах машин сургалтын загвар

## 📌 Төслийн тухай

Энэхүү төсөл нь Улаанбаатар хотын PM2.5 агаарын бохирдлыг цаг агаарын үзүүлэлтүүд (температур, салхины хурд, чийгшил, даралт гэх мэт) ашиглан машин сургалтын аргаар таамаглах зорилготой.

Бид гурван төрлийн регрессийн загварыг харьцуулсан:
- **Linear Regression** (R² = 0.517)
- **Bayesian Ridge** (R² = 0.517)
- **Decision Tree** (R² = 0.535) – хамгийн сайн

Өгөгдлийг **Open‑Meteo API**-аас 2019–2024 оны хугацаанд цагийн нарийвчлалтайгаар татаж, цэвэрлэсэн.

## 📊 Гол үр дүн

- **Decision Tree** хамгийн өндөр R² = 0.535 – PM2.5-ийн хэлбэлзлийн 53.5%-ийг цаг агаар тайлбарлаж чаддаг.
- **Температур** хамгийн чухал хүчин зүйл (53.4%).
- **Салхины хурд** хоёр дахь чухал (18.9%).
- Халаалтын улиралд (10–4-р сар) PM2.5 дунджаар 3–4 дахин өндөр байна.
