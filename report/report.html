# Хураангуй {#sec-abstract}

Энэхүү төслийн ажлаар Улаанбаатар хотын PM2.5 агаарын бохирдлыг цаг агаарын үзүүлэлтүүдийн тусламжтайгаар машин сургалтын аргаар таамаглах загвар боловсруулав. Open‑Meteo API‑аас 2019–2024 оны хугацааны цаг агаар болон агаарын чанарын өгөгдлийг цуглуулж, шүүн боловсруулсан.

Гурван загварыг харьцуулав: **Linear Regression**, **Bayesian Ridge**, **Decision Tree**. Үр дүнгээс харахад **Decision Tree** загвар $R^2 = 0.535$ гүйцэтгэлтэй хамгийн сайн ажиллалаа. Температур буурах тусам PM2.5 эрс нэмэгдэх хандлага илэрч, энэ нь Улаанбаатарын халаалтын улирал (10–4-р сар) дахь нүүрс, мод шатаах галлагаатай шууд холбоотой болохыг загварын дүн шинжилгээ баталгаажуулав. Салхины хурд агаарын бохирдлыг цэвэрлэхэд чухал үүрэг гүйцэтгэдэг нь корреляц шинжилгээнд –0.47 утгаар илэрсэн.

Загвар нь цаг агаарын нөхцөл мэдэгдсэн тохиолдолд PM2.5-ийг тооцоолох боломжтой тул цаг агаарын урьдчилсан мэдээг хослуулан агаарын чанарын богино хугацааны таамаглал гаргах үндэс болж чадна.

# Өгөгдлийн Тайлбар {#sec-data}

## Эх Сурвалж

Өгөгдлийг **Open‑Meteo**‑ийн API‑аас татав:

- **Open‑Meteo Weather API** — температур, чийгшил, салхины хурд, хур тунадас, гадаргын даралтыг цагийн нарийвчлалтайгаар өгдөг нээлттэй эх сурвалж [@zippenfenig2023].
- **Open‑Meteo Air Quality API** — PM2.5 концентрацийг µg/m³-ээр цагийн нарийвчлалтайгаар хангадаг [@openmeteo2024].

Хоёр эх сурвалжийг `datetime` баганаар нэгтгэж ашигласан. Улаанбаатар хотын координат (47.92°N, 106.91°E) дээр суурилж **2019.01.01–2024.12.31** хугацааг хамарсан.

Арга Загварын Танилцуулга

Linear Regression (Шугаман регресс)

Шугаман регресс нь оролт (Х) болон гаралт (у) хувьсагчдын хоорондох шугаман харилцааг олох хамгийн үндсэн регрессийн загвар юм.

[ = _0 + _1 x_1 + _2 x_2 + + _k x_k ]

Коэффициент \(\beta\) нь тухайн хувьсагчийн нэгж нэмэгдэхэд PM2.5 хэр өөрчлөгдөхийг тайлбарладаг. Стандартчлал (StandardScaler) хэрэглэж \(\mu=0, \sigma=1\) болгосноор коэффициентүүдийг шууд харьцуулах боломжтой болголоо.

Bayesian Ridge Regression (Байесын Ridge регресс)

Байесын Ridge нь шугаман регрессийн Байесын хувилбар бөгөөд коэффициентийн prior тархалтыг Гаусс гэж үзнэ. Regularization-ийн тусламжтайгаар хэт тохирлоос зайлсхийдэг бөгөөд коэффициент бүрийн тодорхойгүйн интервал (95% CI) гаргах давуу тал бий:

[ P(|X,y) P(y|X,) P() ]

Энэ загварын давуу тал нь таамаглалын найдвартай байдлыг тоогоор илэрхийлж чаддагт оршино (max_iter=500).

Decision Tree Regressor (Шийдвэрийн мод)

Шийдвэрийн мод нь өгөгдлийг дахин дахин хоёр хуваах замаар шугаман бус харилцааг илрүүлдэг загвар. Хуваалт бүрд MSE критерийг хэрэглэв:

[ MSE = _{i=1}^{n}(y_i - {y})^2 ]

max_depth=6, min_samples_leaf=50 тохируулж хэт тохирлоос зайлсхийсэн. feature_importances_ нь хувьсагч бүрийн чухлыг тооцдог — interpretable загвар тул удирдамжийн шаардлагыг хангана.

6. Үнэлгээ

Гурван метрик: MAE, RMSE, R².

from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

def evaluate(name, y_true, y_pred):
    mae = mean_absolute_error(y_true, y_pred)
    rmse = np.sqrt(mean_squared_error(y_true, y_pred))
    r2 = r2_score(y_true, y_pred)
    print(f'[{name}] MAE={mae:.4f} RMSE={rmse:.4f} R2={r2:.4f}')

Decision Tree загварын scatter plot нь шугаман загваруудаас ялгаатай: цэгүүд хэвтээ зурвас (band) хэлбэртэй тархаж байна (навч бүрт тогтмол дундаж утга). Гэсэн хэдий ч R²=0.535 нь шугаман загваруудын 0.517-оос өндөр бөгөөд сөрөг таамаглал байхгүй.

Загваруудын R² харьцуулалт

Linear Regression болон Bayesian Ridge ижил R²=0.517, Decision Tree R²=0.534 (өөрөөр хэлбэл 0.535). Энэ нь агаарын бохирдлын хэлбэлзлийн 53.5% -ийг цаг агаараар тайлбарлаж байгаа бөгөөд үлдсэн 46.5% нь бусад хүчин зүйлээс (замын хөдөлгөөн, үйлдвэрийн ялгаруулалт, гэр хорооллын шаталт г.м.) хамаарч байна.

Heating_season (0.4%) маш бага importance-тай — учир нь температур аль хэдийн халаалтын улирлын мэдээллийг агуулж байгаа (multicollinearity).

Bayesian Ridge — Тодорхойгүйн интервал

Байесын Ridge загварын 95% тодорхойгүйн интервал (цэнхэр бүс) нь бодит утгуудын (хар шугам) ихэнхийг хамарч байна. Гэвч PM2.5 маш өндөр (60+ µg/m³) болох тохиолдолд зарим бодит утга интервалаас гадагш гарч байна. Энэ мэдээлэл нь бодлого гаргагчдад таамаглалын найдвартай байдлыг үнэлэх чухал хэрэгсэл болно.

Яагаад температур хамгийн чухал?

Улаанбаатарт халаалтын улиралд (10-р сараас 4-р сар) гэр хорооллын өрхүүд нүүрс, мод, хог хаягдлаа шатаадаг. Температур буурах тусам шатаах хэмжээ нэмэгдэж, PM2.5 ялгаралт эрс нэмэгддэг. Салхины хурд нь бохирдлыг сарниулахад чухал үүрэгтэй (корреляц –0.47).

Үр дүнгийн статистик тайлбар

R² = 0.535 гэдэг нь цаг агаарын хүчин зүйлс PM2.5-ийн хэлбэлзлийн тал орчмыг тайлбарлаж чадна гэсэн үг. Үлдсэн хэсэг нь хүний үйл ажиллагаа (замын хөдөлгөөн, үйлдвэрийн ажиллагаа, гэр хорооллын шаталт) болон улирлын бус бусад хүчин зүйлээс хамаарна. Decision Tree-ийн MAE ~6 µg/m³ нь дунджаар 6 нэгжээр алдаж байгаа гэсэн үг.

Загварын хязгаарлалт

  1. Цаг агаараас хамааралтай — ялгаруулалтын шууд өгөгдөл ороогүй тул яаралтай арга хэмжээний нөлөөг таамаглах боломжгүй. Weather forecast оролт болговол 24–72 цагийн таамаглал боломжтой.
  2. R²=0.535 = 46.5% нь бусад хүчин зүйлээс хамаарна (замын хөдөлгөөн, үйлдвэр, гэр хороолол).
  3. Нэг цэгийн координат дээр суурилсан — хотын өөр хэсгүүдэд ялгаатай байж болно.
  4. Цагийн нарийвчлалтай боловч микро-нөхцлүүдийг бүрэн барьж чадахгүй.
